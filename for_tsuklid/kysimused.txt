1.Milline on for-tsükli põhisüntaks Bashis?
for muutuja in väärtused; do  käsud; done

2.Mis vahe on lihtsate väärtuste ja jutumärkides väärtuste vahel tsüklis?
Lihtsad väärtused eraldatakse tühikutega, jutumärkides väärtust käsitletakse ühe tervikunaka siis,
kui see sisaldab tühikuid

3.Mida teeb käsu asendamine (command substitution) tsüklis? Too näide.
Käsu asendamine kasutab käsu väljundit tsükli väärtustena.
for user in $(cut -d: -f1 /etc/passwd); do
    echo "Kasutaja: $user"
done

4.Milleks kasutatakse muutujat IFS?
IFS määrab, milliste märkide järgi jagatakse tekst osadeks. Vaikimisi on selleks tühik,
tabulaator ja reavahetus.

5.Miks ei ole soovitatav kasutada for file in $(ls)? Mis on parem lahendus?
Failinimed võivad sisaldada tühikuid ja siis võib tekkida vigu.
for file in *.txt
do
    echo $file
done

6.Kuidas näeb välja C-stiilis for-tsükkel Bashis?
for ((i=1; i<=5; i++))
do
    echo $i
done

7.Kuidas panna C-stiilis tsükkel lugema ainult paarisarve?
for ((i=2; i<=20; i+=2))
do
    echo $i
done
